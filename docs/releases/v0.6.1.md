# Crate v0.6.1

Crate 0.6.1 mejora la revisión de diferencias durante la sincronización de
dispositivos.

## Device Sync

- Los grupos de artista de la comparación se muestran en orden alfabético de
  A a Z, tanto para la biblioteca local como para el dispositivo.
- La vista de resultado conserva el mismo orden para facilitar la revisión
  antes de aplicar los cambios.
- Las agrupaciones por álbum mantienen su comportamiento anterior y el orden
  interno de los temas no cambia.

## Verificación

- `npm test`
- `npm run test:integration`
- `npm run typecheck`
- `git diff --check`
