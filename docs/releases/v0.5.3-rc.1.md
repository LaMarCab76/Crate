# Crate v0.5.3-rc.1

Esta versión candidata recupera mejoras útiles de la implementación histórica
de OneDrive sobre la arquitectura actual, sin reintroducir su código obsoleto.

## OneDrive y metadatos técnicos

- Las pistas remotas enriquecen en segundo plano codec, bitrate, sample rate,
  bit depth, canales y duración mediante trabajos cancelables.
- Las lecturas parciales usan `Range` y conservan el `ETag` del contenido para
  invalidar resultados cuando cambia el archivo remoto.
- Al eliminar una biblioteca o cerrar Crate, los trabajos pendientes se
  cancelan y esperan antes de liberar sus recursos.

## Device Sync

- Las pistas de OneDrive se preparan en archivos temporales seguros antes de
  copiarse a un dispositivo.
- El staging conserva el `mtime` original y limpia los temporales tanto al
  completar como ante un error.

## Publicación

- Esta RC se distribuye como prerelease privada y requiere instalación manual.
- Los paquetes de macOS están firmados ad hoc, no notarizados, y pueden requerir
  una autorización manual de Gatekeeper.
- El workflow deja de crear cachés npm de alta rotación y elimina sus artefactos
  temporales al finalizar; los instaladores publicados en Releases se conservan.

## Verificación

- `npm test`
- `npm run test:integration`
- `npm run typecheck`
- `npm run build`
- `npm run verify:bass -- --load`
