# Crate v0.4.3

Patch release: GitHub Releases auto-update support plus preferences UI for
manual update checks.

## Highlights

### App updates
- Packaged builds now check GitHub Releases through `electron-updater` shortly
  after startup.
- Preferences now includes an `Actualizaciones` tab with manual check,
  download, and restart/install controls.
- Update state is exposed through a typed IPC/preload API and broadcast to the
  renderer as availability, download progress, install readiness, and errors
  change.
- Development builds clearly show updates as unavailable instead of attempting
  to contact the release feed.

### Packaging
- `electron-builder` now publishes against `LaMarCab76/LocalLibrary`.
- macOS builds include zip artifacts and blockmaps required by the updater in
  addition to DMG artifacts.
- The release workflow uploads the updater zip assets together with
  `latest-mac.yml`.

## Verification

- `npm run typecheck:node`
- `npm run typecheck:web`
- `node --test $(rg --files -g '*.test.mjs')` (154 tests)
- `npm run build`
- Renderer update preferences smoke test in the in-app browser against the
  production build output

## Known issues

- `npm audit --omit=dev` still reports the pre-existing moderate
  `node-taglib-sharp -> uuid` advisory. The suggested automated fix downgrades
  `node-taglib-sharp` across a major version boundary, so it is not included in
  this release.
