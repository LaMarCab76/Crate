# Crate v0.3.2

Patch release with the current set of changes since v0.3.1.

## Highlights

- Playback and audio stack refinements in main-process audio engine paths (FFI layer, gapless queue behavior, and channel/IPC coordination).
- Renderer and player UX updates across playback surfaces and list views.
- Store updates for library, queue, playback, and settings flow consistency.
- New utilities and tests around progressive buffering, track deletion/lifecycle handling, and next-track toast behavior.
- IPC contract and preload updates to keep main/renderer behavior aligned after the above changes.

## Verification

- `npm run typecheck`
- `npm run build`
