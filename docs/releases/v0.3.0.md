# Crate v0.3.0

Major feature release expanding Crate beyond the v0.1.0 alpha: device sync, downloads, lyrics, and a redesigned player.

## Highlights

### Player & UI
- Reworked `PlayerPane`, `NowPlayingFull`, and `PlayerBottomBar` with refined transitions, layout, and color extraction.
- New `FullScreenQueue` view for the expanded now-playing experience.
- Redesigned `SpectrumVisualizer` and `EQBars` with unified bands and improved metering.
- Unified typography across the renderer (`globals.css`, lyrics store).
- New `TrackLoadingOverlay` and clearer playback state surfaces.

### Lyrics
- Expanded `LyricsPanel` with candidate selection, synced display, and persisted settings.
- New lyrics database migration (`0010_lyrics.sql`) and `LyricsRepo`.
- Dedicated `lyrics-channel` IPC.

### Devices
- Full `DeviceSyncService` for portable players, including artwork optimization and library tracking.
- `RockboxThemeScanner` with tests for theme-aware sync targets.
- `DeviceConnectModal`, `DeviceLibraryView`, and reworked `DevicesView`.
- Device-sync DB migrations (`0011`–`0013`).

### Downloads
- New `DownloadManager` with `QobuzProvider` and `TidalProvider`.
- `HarCredentialExtractor` (with spec) and `CredentialStore` for secure credential handling.
- `downloads-channel` IPC and `download_jobs` migration.

### Playback Analysis
- `PlaybackAnalysisService` and `PlaybackAnalysisRepo` with caching migrations (`0015`, `0017`).
- `library_scan_log` migration and repo for import diagnostics.

### Infra
- IPC validation helpers and throttling utilities.
- `FolderRemovalConfirmModal` for safer library edits.

## Install Notes

- **macOS**: download the DMG (x64 or arm64). Builds are unsigned and not notarized — open from System Settings the first time.
- **Windows**: download the NSIS `.exe` installer (x64).
- **Linux**: download the `.AppImage` or `.deb` package.
- Auto-update metadata (`latest-mac.yml`, `latest.yml`, `latest-linux.yml`) is attached alongside each platform's installers.

## Verification

- `npm run typecheck`
- `npm run build`
- `npm run dist:mac` / `dist:win` / `dist:linux`
