# Crate v0.3.3

Patch release with the current set of changes since v0.3.2.

## Highlights

- New Device Sync view with planning, layout, and overview utilities (`DeviceSyncView`, `deviceSyncPlan`, `deviceOverview`).
- Device sync service, Rockbox theme scanner, and IPC channel updates for full device-sync flow.
- Audio progressive buffering refactored into a dedicated module with test coverage.
- Gapless controller and FFI layer fixes aligned with the new buffering strategy.
- Renderer and UI refinements across Sidebar, Toolbar, PlayerPane, PlayerBottomBar, and DevicesView.
- Store updates for device, playback, and queue state consistency.
- Shared IPC contract and preload updates to keep main/renderer in sync.

## Verification

- `npm run typecheck`
- `npm run build`
