# Crate v0.5.2

Esta actualización simplifica los indicadores de origen en las vistas de
álbumes para que la carátula y la información musical mantengan el protagonismo.

## Vista de álbumes

- El detalle de un álbum conserva el nombre y proveedor de su biblioteca, pero
  ahora los muestra sin borde, fondo ni recuadro.
- La grilla de carátulas muestra un único indicador de origen: una carpeta para
  bibliotecas locales o una nube para bibliotecas de OneDrive.
- Los indicadores compactos conservan el nombre accesible y el tooltip con la
  ubicación completa.
- Las demás vistas mantienen su presentación configurable de fuentes.

## Aviso para macOS

- Los usuarios que instalaron Crate v0.5.1 en macOS deberán descargar e instalar
  v0.5.2 manualmente una vez. El build v0.5.1 tenía firma ad hoc y deshabilitaba
  la instalación automática de actualizaciones por seguridad.
- Una versión firmada con Developer ID y notarizada puede volver a habilitar el
  canal automático para actualizaciones posteriores.

## Verificación

- `npm test`
- `npm run test:integration`
- `npm run typecheck`
- `npm run build`
- Validación visual real de la grilla y del detalle de álbum en Electron usando
  una copia temporal aislada del perfil.
