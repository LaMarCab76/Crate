# Crate v0.4.2

Patch release: device artwork optimization fixes and UI polish for the v0.4
device-sync workflow.

## Highlights

### Artwork optimization
- Oversized MP3 artwork is now replaced when the resized image satisfies the
  configured maximum edge, even if re-encoding does not make the image smaller
  on disk.
- Reported `bytesSaved` remains non-negative, so resolution-only fixes count as
  optimized without claiming fake byte savings.
- Temporary artwork writes keep the original audio extension after the temp
  marker, preserving format detection during atomic replacement.
- Post-optimization validation still rejects any artwork result that remains
  outside the configured limit.

### Device sync UI
- The artwork optimization action keeps the button label on one line at compact
  widths.
- After optimization completes, the screen moves through an explicit refresh
  state while artwork is re-analyzed, so the app no longer appears stuck.
- Artwork analysis yields during long batches to keep the renderer responsive.
- General and artwork-specific search bars now inherit the active app background
  tint instead of using a fixed elevated panel color.

### Packaging
- Release metadata now points at `v0.4.2`.
- The transitive `tmp` build dependency was refreshed to `0.2.7` through
  `npm audit fix`, removing the non-forced audit finding for `tmp`.
