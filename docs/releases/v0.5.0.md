# Crate v0.5.0

Minor release: single-track album move tooling, safer device sync/lyrics behavior,
and scan pipeline improvements that reduce sync surprises while preserving local
state.

## Highlights

### Librería y metadatos
- Added **Mover a álbum...** for one track at a time.
  - It validates destination slot and duplicates before writing.
  - Destination filenames are normalized, conflict-safe, and follow disc-aware
    numbering.
  - The move is done via a temp rewrite on a copied file; it now preserves a
    single `track` row (`UPDATE` in-place), and only moves DB metadata after the
    file + sidecar operation succeeds.
- Introduced a dedicated `MusicBrainzMetadataClient` for album-move matching.
- Metadata extraction options now support skipping embedded artwork, which is used
  by scan-like paths to avoid unnecessary metadata-heavy parsing.
- Album and track query behavior was hardened so empty albums are no longer shown
  in album listings and track list pagination is protected against invalid
  `limit`/`offset` values.

### Device sync y lyrics
- Device scan was split into a reusable scan core with:
  - metadata read concurrency, progress events and summary output,
  - `database.ignore` / `database.unignore` path handling,
  - audio-only scan results that intentionally ignore `.lrc` sidecars.
- Device sync now supports **local album move propagation**:
  - local moves are reflected in sync plans (pc_to_device / bidirectional_safe),
  - `device_to_pc` exposes a warning instead of forcing those moves,
  - per-device journal state tracks move satisfaction.
- Lyrics are no longer propagated by Device Sync:
  - `.lrc` sidecars are not copied/imported between PC and MP3/DAP,
  - embedded lyrics are not read to decide propagation,
  - missing `fetch_missing_lyrics` is treated as legacy/compatibility.
- Device library loading now supports lightweight background/progress
  invocation to keep reconnection flows responsive.

### Infra de base de datos
- Added migration `0022_track_album_moves.sql` (per-track move ledger).
- Added migration `0023_cleanup_orphaned_entities_on_track_update.sql` to clean up
  orphaned artists/albums/genres and keep entity stats in sync after in-place
  track metadata updates.

## Correcciones principales de bugs

- Fixed album move edge cases that could overwrite destination audio files or
  leave partially moved data after DB failures.
- Removed Device Sync lyrics propagation so MP3/DAP sync no longer copies,
  imports, or probes local/embedded lyrics.
- Fixed incorrect library behavior where invalid pagination parameters could
  produce undefined track slices in list queries.
- Fixed stale side effects in device reconnection flows where a full scan blocked
  UI registration; now library refresh can run in the background.
