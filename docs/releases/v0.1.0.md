# Crate v0.1.0

First downloadable alpha of Crate.

## Highlights

- Desktop Electron build for macOS.
- Library, albums, artists, settings, playback layout, queue, and player surfaces are available in the packaged app.
- Recently Added now stays newest-first and does not inherit album filters.
- Player panel and bottom player transitions were polished for the first packaged release.
- The Up Next notice was refined for both side-panel and bottom-player layouts.

## Install Notes

- Download the DMG from the GitHub release assets.
- This first build is unsigned and not notarized. macOS may require opening it from System Settings after the first launch attempt.
- Keep the DMG and release notes attached to the `v0.1.0` GitHub Release.

## Verification

- `npm run typecheck`
- `npm run build`
- `npm run dist:mac`
