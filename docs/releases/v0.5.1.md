# Crate v0.5.1

Esta versión amplía Crate con bibliotecas locales y de OneDrive dentro de un
catálogo unificado, copias espejo y migraciones recuperables entre ubicaciones.
También refuerza reproducción, descargas, Device Sync, seguridad IPC y el flujo
de publicación multiplataforma.

## Bibliotecas locales y OneDrive

- Nuevo asistente inicial y panel de ubicaciones para registrar varias
  bibliotecas locales o de OneDrive, con nombres, iconos y badges de origen.
- Integración con cuentas personales de OneDrive mediante OAuth de cliente
  público, caché MSAL cifrada y credenciales protegidas por el sistema operativo.
- Indexación incremental con Microsoft Graph delta, refresco periódico y estado
  portátil en `.crate/library.yaml`.
- Reproducción de pistas de OneDrive mediante descarga completa y cancelable a
  memoria, sin confundir identificadores cloud con rutas del filesystem.
- Acción para mover una pista local a una biblioteca de OneDrive con validación
  de identidad, subida reanudable, rollback de base de datos y política de
  conservación o papelera para el archivo original.
- Los scans locales ahora conservan el catálogo cuando una raíz o subcarpeta no
  está disponible, ignoran symlinks y detectan renombres que solo cambian mayúsculas.
- Se rechazan raíces locales o remotas solapadas antes de incorporarlas.

## Backups y migraciones

- Copias espejo local/local, local/OneDrive, OneDrive/local y
  OneDrive/OneDrive con planificación persistente, revisión del primer lote y
  detección de divergencias en el destino.
- Los mirrors pueden pausarse, reanudarse, promoverse a biblioteca o
  desvincularse sin borrar contenido del usuario.
- Migraciones durables de tipo relocate o merge entre ubicaciones locales y
  OneDrive, con journal por acción, deduplicación, renombre de colisiones,
  aprobación previa, recuperación tras reinicio y limpieza reintentable.
- Las migraciones preservan identidades de carpetas y pistas, playlists,
  favoritos y estado de usuario cuando un merge elimina duplicados.

## Reproducción y cola

- Persistencia de cola, repeat y shuffle entre sesiones.
- Shuffle recorre todas las pistas no visitadas aunque la reproducción comience
  en un índice aleatorio intermedio; repeat-all reinicia el ciclo al agotarlo.
- Las cargas de audio se serializan y cancelan de forma segura para evitar que
  una pista anterior reemplace a la selección más reciente.
- Gapless respeta la preferencia configurada y el modo exclusivo puede restaurar
  correctamente pistas locales o cloud después de reinicializar BASS.
- Se endurecieron los límites de RAM, timeouts y liberación de buffers usados por
  reproducción y precarga progresiva.

## Device Sync, descargas y lyrics

- Device Sync puede copiar pistas de OneDrive a un dispositivo mediante staging
  temporal y rutas sanitizadas; los destinos PC siguen limitados a bibliotecas
  locales reales.
- Los journals de sync viven en el host, se revalidan al reanudar y comprueban
  fingerprints antes de reutilizar acciones preparadas.
- Los destinos de descarga usan reservas atómicas y nombres seguros; los jobs
  interrumpidos se recuperan al iniciar y las transferencias validan identidad,
  tamaño y escritura final.
- Importar credenciales desde HAR aplica límites de tamaño, valida estructura y
  evita conservar payloads sensibles; el artwork remoto se obtiene desde el
  proceso principal.
- La recuperación de lyrics legacy crea un archivo checksummed antes de eliminar
  tablas antiguas y las escrituras `.lrc` usan reemplazo atómico.
- Device Sync continúa sin copiar ni importar lyrics entre el equipo y el DAP.

## Álbumes, metadatos y base de datos

- **Mover a álbum...** valida slots y duplicados, usa el tracklist oficial de
  MusicBrainz cuando está disponible y actualiza la misma fila de pista solo
  después de completar archivo y sidecar.
- Los nombres de destino son seguros ante colisiones y respetan numeración de
  disco; reemplazar calidad igual o menor requiere confirmación explícita.
- Se añadieron las migraciones `0025` a `0030` para métricas de playlists,
  reservas de descargas, ubicaciones, journals de mirrors, presentación y
  migraciones de bibliotecas.
- El migrador aplica cada archivo en su propia transacción, puede reparar estados
  legacy conocidos y rechaza ejecución dentro de una transacción externa.

## Seguridad y distribución

- El preload se empaqueta como CommonJS sandboxed con `contextIsolation`, sin
  Node en renderer, y los handlers IPC validan el frame superior y el origen
  exacto antes de procesar llamadas privilegiadas.
- Navegación, ventanas externas, rutas autorizadas, recursos `crate://` y
  descargas remotas tienen validaciones adicionales.
- El proceso principal recupera el renderer si termina inesperadamente y coordina
  el apagado de audio, workers, mirrors, migraciones y estado persistente.
- El release descarga y valida el runtime BASS específico de cada plataforma,
  ejecuta tests e integración en los tres sistemas y comprueba los recursos ya
  empaquetados antes de subir artefactos.
- La ruta normal de macOS exige firma `Developer ID Application`, hardened
  runtime, notarización y ticket stapled. Para v0.5.1 se usó explícitamente la
  excepción manual ad hoc porque la cuenta de publicación aún no dispone de
  membresía Apple Developer.

### Aviso para macOS

- Los artefactos v0.5.1 de macOS tienen firma ad hoc y no están notarizados.
- Gatekeeper puede requerir un primer intento de apertura y luego autorizar
  Crate desde **Ajustes del Sistema → Privacidad y seguridad → Abrir de todos
  modos**.
- La instalación automática de actualizaciones está deshabilitada en este build;
  las siguientes versiones deberán instalarse manualmente hasta publicar con
  Developer ID y notarización.

## Requisitos y limitaciones de OneDrive

- OneDrive es opcional y admite cuentas personales de Microsoft.
- Requiere el Application (client) ID de una app pública configurada para cuentas
  personales con permisos delegados `Files.ReadWrite` y `User.Read`; no se usa ni
  se almacena un client secret.
- En pistas cloud no están disponibles la escritura de lyrics, edición/completado
  de metadatos, **Mover a álbum...** ni el análisis persistente de waveform/barras.
- Device Sync puede usar una pista cloud como origen hacia el dispositivo, pero
  no usa OneDrive como destino PC ni elimina fuentes cloud desde un plan de sync.
