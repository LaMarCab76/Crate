# Crate v0.4.4

Patch release: global activity center for renderer notifications and progress.

## Highlights

### Activity center
- Added a top-toolbar activity button with active/unread badge state.
- Added a floating activity center with pinned and fullscreen modes.
- Moved global device sync, artwork, lyrics, library import, download, update,
  and new-volume activity out of bottom notifications and into the activity
  center.
- Activity rows now navigate to the matching app section when clicked, while
  explicit row actions remain available for volume classification and related
  flows.
- Running activity now shows an animated loader instead of a notification bell.

### Devices and libraries
- New volumes can be handled from the activity center: connect as MP3, add as a
  library, ignore, or open Preferences > Libraries.
- Device connect handling is centralized from `App` so Sidebar, Preferences,
  and activity actions use the same modal.

### Updates
- Non-actionable update states such as development-only GitHub Releases
  unavailability no longer create persistent activity entries.
- Previously persisted non-actionable update activities are discarded on
  hydration.
