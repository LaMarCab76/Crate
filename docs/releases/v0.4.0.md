# Crate v0.4.0

Minor release: lyrics move to `.lrc` sidecars, device sync gains online lyrics
fetching, bidirectional conflict bases, and artwork optimization, plus several
device-sync UI fixes.

## Highlights

### Lyrics
- Lyrics are now stored in `.lrc` sidecar files next to the audio (plus embedded
  tags as a read source) as the single source of truth. DB-cached lyrics are
  written out to sidecars by `materializeLyricsSidecars()` before the database
  tables are dropped, so no content is lost (migration `0019_drop_lyrics_tables`).
- Removed the DB lyrics layer (`LyricsRepo`, `CacheLyricsProvider`).

### Device sync
- New per-device toggle to fetch missing lyrics online (LRCLIB) during PC→device
  sync (migration `0018_device_fetch_lyrics`, `lyricsSyncDecision`).
- Per-device conflict base for bidirectional sync — `pc` / `device` / `review`,
  remembered in the device's Configuración tab (migration `0020_device_sync_base`).
- Artwork optimization decisions during sync (`artworkOptimizeDecision`,
  `ArtworkOptimizer`), with `trackFingerprint` and `dirEntryKind` helpers.

### Device sync UI
- Diferencias/Resultado are now viewable (read-only) while a sync is running; the
  stepper tabs stay navigable and live progress remains visible in the header.
- Returning to the sync screen while a sync is still running lands on the live
  progress step instead of an editable diff that looked like a cancelled sync.
- The non-functional Atrás/Cerrar buttons are hidden during live progress.
- The "Sync interrumpida" pending-journal card is hidden while a sync is actively
  running, so an in-progress sync no longer looks interrupted.

### Other
- Settings, Sidebar, Toolbar, and App refinements; styling updates.

## Verification
