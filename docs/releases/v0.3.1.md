# Crate v0.3.1

Patch release focused on reliability, packaging stability, and minor playback and sync refinements.

## Highlights

- Stability and packaging polish across the existing installer matrix (macOS, Windows, Linux).
- Small reliability fixes around startup/resume flows and background sync behavior.
- Updated release metadata and changelog alignment for the v0.3.1 release.

## Install Notes

- **macOS**: use the DMG (`x64` or `arm64`).
- **Windows**: use the NSIS `.exe` installer (`x64`).
- **Linux**: use `.AppImage` or `.deb`.

## Verification

- `npm run typecheck`
- `npm run build`
- `npm run dist:mac` / `dist:win` / `dist:linux`
