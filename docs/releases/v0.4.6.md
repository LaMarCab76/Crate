# Crate v0.4.6

Patch release: equalizer runtime fixes, richer player visuals, metadata and
lyrics workflow polish, and a security-focused Electron build-chain refresh.

## Highlights

### Equalizer and audio
- The EQ now uses BASS_FX BQF peaking filters with a configurable 5-32 band
  layout. Quick picks cover 10, 15, 20 and 31 bands, while arbitrary counts are
  log-spaced across the audible range.
- Presets and saved curves are interpolated onto the active band layout, so
  switching band counts preserves the shape instead of truncating gains.
- The EQ settings panel now uses a unified visual surface: live spectrum behind,
  response curve above it, thumb-only vertical sliders, and a live dB readout
  while dragging.
- The spectrum in the EQ panel defers heavy LED mounting by one frame and avoids
  hover-only darkening, reducing entry jank and keeping touch/pen editing usable.
- Added a volume leveler backed by LUFS/ReplayGain-style math, clipping
  prevention, and the playback analysis cache as a fallback for untagged tracks.

### Player visuals
- Artwork changes now cross-dissolve in the full player instead of cutting
  directly between covers.
- Player, lyrics side pane and content backgrounds can use a three-color artwork
  palette, giving the UI a richer tint without losing the current fallback color
  behavior.
- The bottom player dock now animates between the side pane and horizontal bar
  with coordinated open/close timing.
- Fullscreen playback gets an optional embedded spectrum layer and an upper-zone
  "Up next" toast that stays clear of the transport controls.
- Spectrum LED rendering drops per-segment compositor promotion, avoiding large
  mount-time composite spikes.

### Library, lyrics and metadata
- Metadata completion now opens as a dedicated "Completar metadatos" view with
  current-vs-proposed columns, track-level selection and field-level selection.
- Library, import and media action triggers now route to the metadata fix view
  instead of a floating modal.
- The lyrics library overview uses a per-folder `.crate/lyrics-index.json` cache
  and a virtualized row list, so large libraries no longer require re-reading
  every sidecar or embedded tag on each open.
- Lyrics auto-scroll behavior, track deletion cleanup, and library background
  worker plumbing received focused regression coverage.

### Packaging and security
- Updated the release toolchain to Electron 40, electron-builder 26,
  electron-vite 5, Vite 7 and @vitejs/plugin-react 5.
- Added an npm override for `uuid` so the `node-taglib-sharp` transitive tree no
  longer carries the known `uuid <11.1.1` advisory.
- `npm audit --audit-level=moderate` now reports zero vulnerabilities.
